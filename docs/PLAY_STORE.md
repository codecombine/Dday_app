## 스토어 등록정보
**간단한 설명** (80자 이내)
> 가족끼리 일정·기념일·사진을 한곳에서. 약수집·옥수집·진주집, 집마다 공간을 나눠 함께 봐요.

**자세한 설명**
> 한지붕은 가족이 함께 쓰는 일정·기념일·사진 앱입니다.
>
> ■ 공간별로 나눠 보기
> 약수집, 옥수집, 진주집처럼 집마다 공간을 만들고, 일정과 사진을 필요한 공간에만 공유하세요. 같은 일정이 여러 공간에 함께 보이고, 고치면 모든 곳에 반영됩니다.
>
> ■ 기념일·D-Day
> 아이 태어난 날부터 며칠째인지, 100일·1000일·주년이 언제인지 자동으로 알려줘요. 부모님 음력 생신도 매년 양력 날짜로 바꿔 계산합니다.
>
> ■ 가족 캘린더
> 가족 일정을 달력으로 한눈에 보고, 구글 캘린더와 실시간으로 맞춰 둘 수 있어요.
>
> ■ 가족 앨범과 중복 정리
> 사진은 원본 하나만 보관하고 가족이 함께 봐요. 카톡으로 주고받으며 생긴 화질 낮은 사본이나 같은 사진은 관리자가 확인한 뒤 한 번에 정리할 수 있어요.
>
> ■ 쉬운 초대
> 카카오톡으로 초대 링크를 보내면 버튼 한 번으로 가입과 참여가 끝나요. 앱을 쓰지 않는 할머니·할아버지도 이름만 등록해 일정에 표시할 수 있어요.
>
> ■ 알림과 위젯
> 기념일·일정 알림, 가족이 일정을 추가하거나 사진을 올렸을 때 알림, 홈 화면 D-Day 위젯을 지원합니다.

## 권한 설명 (심사에서 물어볼 때)
| 권한 | 이유 |
|---|---|
| 사진 및 동영상 (READ_MEDIA_IMAGES) | 가족 앨범에 올릴 사진 선택, 사용자가 켠 경우 새 사진 자동 올리기 |
| 미디어 위치 (ACCESS_MEDIA_LOCATION) | 원본 사진의 촬영 정보를 그대로 보관 |
| 캘린더 (READ/WRITE_CALENDAR) | 사용자가 고른 폰 캘린더 일정을 가져오기 |
| 알림 (POST_NOTIFICATIONS) | 기념일·일정 알림, 가족 소식 알림 |

## 내부 테스트 배포 순서
1. 테스트 → 내부 테스트 → 테스터 → 이메일 목록 만들기 → 가족 구글 계정 이메일 추가
2. 새 버전 만들기 → `eas build -p android --profile production`으로 만든 AAB 업로드 → 출시 노트("첫 테스트 버전") → 검토 후 출시
3. 테스터 탭의 **참여 링크**를 가족에게 카카오톡으로 보내기 → 링크에서 "테스터 되기" → Play 스토어에서 설치
4. 이후 업데이트는 새 AAB만 올리면 가족 폰에 자동으로 설치됩니다
